Rozkład
jazdy

System do pracy z rozkładami jazdy, przystankami i wyszukiwaniem połączeń.

Cel

Projekt jest laboratorium backendu Java, modelowania danych przestrzennych i pracy z narzędziami AI. Rozwijam go etapami, pokazując faktyczny stan zamiast deklarowania gotowego produktu produkcyjnego.

Zakres techniczny

Backend

Java 21, Spring Boot, REST

Dane

PostgreSQL, PostGIS

Uruchamianie

Docker, Docker Compose

Frontend

React

Notatki

Rozdzielenie API, logiki domenowej i dostępu do danych. Wykorzystanie danych geograficznych do pracy z lokalizacją przystanków. Stopniowe rozwijanie projektu i dokumentowanie decyzji technicznych. AI wspiera analizę i refaktoryzację, ale zmiany są weryfikowane przez człowieka.

StatusProjekt własny, rozwijany
